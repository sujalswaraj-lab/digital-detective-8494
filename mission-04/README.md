## My understanding

A compiler usually translates a program before it runs, often producing an executable or another translated form. An interpreter typically processes instructions while the program runs. These are broad descriptions: some implementations combine compilation and interpretation, for example by compiling to bytecode and executing that bytecode in a virtual machine.
