### task 4.2 compare compiler and interpreter

| point | compiler | interpreter |
| --- | --- | --- |
| when translation / execution happens | translates whole source code before program runs | translates and runs instructions line by line at runtime |
| typical output | machine code executable file | direct program execution output |
| one example | c or c++ | python or javascript |
| one advantage | execution is fast because code is already compiled | quick to test and easy to find bugs interactively |

difference between compiler and interpreter:
a compiler converts the entire code into machine language before execution so it runs fast but requires compiling first
an interpreter reads and executes each line directly without creating an executable binary file
compilers detect syntax errors before any code runs while interpreters execute until an error line is reached
languages like python use both by compiling source to bytecode and then interpreting it
