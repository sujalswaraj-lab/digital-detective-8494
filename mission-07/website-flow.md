# Task 7.3 — What happens when a website opens

1. A person enters a website name in the browser. The browser acts as the client that will request the page.
2. The client asks DNS to resolve the domain name to a network address. DNS provides an address that the browser can use to contact the site.
3. The browser opens a connection to the server at that address and uses a protocol such as HTTPS to communicate.
4. The request travels through the local network and routers. Data is carried in packets that are forwarded toward the server.
5. The web server receives the client's request, processes it, and prepares a response, such as page content and related resources.
6. The server sends the response back through the network in packets. The client reassembles the data and handles the response.
7. The browser interprets the returned content and displays the website to the person.
