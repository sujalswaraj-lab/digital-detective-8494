# Task 7.1 — Network concepts

| Concept | Explanation | Example |
| --- | --- | --- |
| LAN (Local Area Network) | Connects devices across a limited area, such as a home, school, or office. | Computers and printers connected within one school building. |
| MAN (Metropolitan Area Network) | Connects networks across a city or metropolitan area. | A city-wide network connecting public offices in different neighborhoods. |
| WAN (Wide Area Network) | Connects networks across large geographic distances. | The internet connects networks around the world. |
| DNS (Domain Name System) | Looks up domain names and returns associated network records, such as IP addresses. | Resolving `example.com` to its IPv4 address records. |
| Router | Forwards network traffic between networks based on where the data needs to go. | A home router forwards traffic between local devices and an internet connection. |
| Protocol | An agreed set of rules for communication between devices or software. | HTTPS rules are used to request and deliver secure website content. |
| Packet switching | Sends data in separate packets that can travel through a network and be reassembled at the destination. | A website response is carried across a network in packets. |
| Client-server | A model where a client requests a service and a server provides it. | A browser requests a web page from a web server. |
