## Understanding

IPOS describes a useful path through a computer system: information enters, the processor works on it with the help of memory, the result is presented, and data can be saved for later. Hardware is the physical equipment; software is the set of programs and instructions that tell the equipment what to do. Everyday systems apply the same ideas to particular tasks, such as dispensing cash or controlling traffic lights.
