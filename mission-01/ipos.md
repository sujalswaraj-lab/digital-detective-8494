# Task 1.1 — Trace an activity using IPOS

## Activity: create and save this mission report

| Stage | What happens | Hardware or component involved |
| --- | --- | --- |
| Input | The report's text and save instructions are entered into the computer system. | Keyboard or another text-input method |
| Processing | The operating system and text-editing software handle the text and save request. The CPU runs their instructions, while RAM holds the active text and program data temporarily. | CPU/processor and RAM |
| Output | The report is shown so a person can read and review it. | Screen/display |
| Storage | Saving writes the report as a file. Committing and pushing it also stores a version in the remote GitHub repository. | SSD or hard drive; network connection and remote storage for the GitHub copy |

## How the stages connect

The text enters the system as input. The processor runs the editor and operating-system instructions that arrange the text and respond to the save request, using RAM for information currently in use. The screen presents the document as output. When it is saved, the operating system writes the file to persistent storage. For this mission, Git then records the files in a commit, and pushing the commit sends it to the remote repository for storage and later access.
